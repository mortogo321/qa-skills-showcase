# Test Cases — Cart & Checkout

Application under test: https://www.saucedemo.com
Related requirements: REQ-CART-01 (add/remove), REQ-CHK-01 (info validation),
REQ-CHK-02 (totals), REQ-CHK-03 (completion)

| ID | Title | Precondition | Steps | Expected Result | Priority | Type |
|---|---|---|---|---|---|---|
| TC-CHECKOUT-001 | Add a single item to the cart | Logged in as `standard_user`, on Products page | 1. Click "Add to cart" on any product. | Button label changes to "Remove"; cart icon badge shows "1". | Critical | Functional / Positive |
| TC-CHECKOUT-002 | Cart badge count reflects multiple items | Logged in as `standard_user`, on Products page | 1. Add 3 different products to the cart via "Add to cart". | Cart badge count shows "3", updating after each addition. | Critical | Functional / Positive |
| TC-CHECKOUT-003 | Remove item from Products page | One item already added to cart | 1. Click "Remove" on the previously added product. | Button reverts to "Add to cart"; cart badge decrements or disappears if count reaches 0. | High | Functional / Positive |
| TC-CHECKOUT-004 | Remove item from Cart page | Two items added to cart, viewing Cart page | 1. Click "Remove" next to one line item on the Cart page. | That item is removed from the list; badge count decrements by 1; remaining item is still listed. | High | Functional / Positive |
| TC-CHECKOUT-005 | Cart persists item list when navigating away and back | One item added to cart, on Products page | 1. Navigate to Cart page. 2. Navigate back to Products via "Continue Shopping". 3. Return to Cart page. | The previously added item is still present with badge count unchanged. | Medium | Functional / State |
| TC-CHECKOUT-006 | Proceed to checkout with empty cart | Logged in, cart is empty | 1. Click cart icon. 2. Click "Checkout". | Application allows navigation to the checkout information step even with no items (no items to purchase); behavior should be verified against expectation of blocking empty checkout. | Medium | Functional / Edge Case |
| TC-CHECKOUT-007 | Checkout blocked when First Name is empty | One item in cart, on Checkout: Your Information page | 1. Leave First Name blank. 2. Fill Last Name and Zip/Postal Code. 3. Click "Continue". | Error banner reads "Error: First Name is required." User remains on the information step. | Critical | Functional / Negative |
| TC-CHECKOUT-008 | Checkout blocked when Last Name is empty | One item in cart, on Checkout: Your Information page | 1. Fill First Name. 2. Leave Last Name blank. 3. Fill Zip/Postal Code. 4. Click "Continue". | Error banner reads "Error: Last Name is required." User remains on the information step. | Critical | Functional / Negative |
| TC-CHECKOUT-009 | Checkout blocked when Zip/Postal Code is empty | One item in cart, on Checkout: Your Information page | 1. Fill First Name and Last Name. 2. Leave Zip/Postal Code blank. 3. Click "Continue". | Error banner reads "Error: Postal Code is required." User remains on the information step. | High | Functional / Negative |
| TC-CHECKOUT-010 | Order total equals item subtotal plus tax | One item with known price in cart, on Checkout: Overview page | 1. Complete valid information step. 2. Review Item total, Tax, and Total lines. | Total = Item total + Tax, calculated correctly to two decimal places, matching displayed tax rate. | Critical | Functional / Data Integrity |
| TC-CHECKOUT-011 | Order total updates correctly with multiple items | Three items with different prices in cart, on Checkout: Overview page | 1. Complete valid information step. 2. Review Item total, Tax, and Total. | Item total equals the sum of all three item prices; Tax is calculated on that subtotal; Total is the sum of both. | High | Functional / Data Integrity |
| TC-CHECKOUT-012 | Successful order completion | One item in cart, valid information submitted, on Checkout: Overview page | 1. Click "Finish". | "Checkout: Complete!" page is shown with confirmation message (e.g. "Thank you for your order!") and a pony/completion graphic; cart badge is cleared. | Critical | Functional / Positive |
| TC-CHECKOUT-013 | Cancel from Checkout: Your Information | One item in cart, on Checkout: Your Information page | 1. Click "Cancel". | User is returned to the Cart page; the item remains in the cart (order is not placed). | Medium | Functional / Negative Path |
| TC-CHECKOUT-014 | Cancel from Checkout: Overview | One item in cart, on Checkout: Overview page | 1. Click "Cancel". | User is returned to the Products page; the item remains in the cart, order is not placed, cart badge count is unchanged. | Medium | Functional / Negative Path |
